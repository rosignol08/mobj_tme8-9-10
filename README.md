# Projet MOBJ : visualisation de netlists

Ce projet est une application graphique développée en C++ avec Qt, destinée à visualiser des netlists.  
Elle permet de charger des cellules, d’afficher leurs symboles et instances, et de naviguer dans le schéma.

## Fonctionnalités
- affichage graphique d’une cellule et de ses composants,
- visualisation des instances,
- navigation dans le schéma,
- déplacement des instances à la souris,
- consultation d’une liste d’instances dans une fenêtre dédiée.
- création de circuit personnalisé exportables.

## Technologies
- C++
- Qt
- CMake

## Compilation
1. Se rendre dans le dossier `build`
2. Taper `cmake ../src`
3. Exécuter `make`
4. Lancer l'exécutable `tme810`
